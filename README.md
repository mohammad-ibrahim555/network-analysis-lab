# Network Analysis Lab

A hands-on network traffic analysis lab documenting my cybersecurity learning through Wireshark, TCP/IP fundamentals, DNS analysis, and HTTP traffic inspection.

## Objectives

* Understand how network communication works.
* Learn to capture and inspect network traffic using Wireshark.
* Study TCP/IP protocols, packet structure, and encapsulation.
* Analyze DNS queries and responses.
* Examine HTTP requests, responses, headers, and status codes.
* Document practical observations through technical notes and screenshots.

## Tools

* Wireshark
* Windows and networking command-line utilities
* Sample packet captures and authorized lab traffic
* Git and GitHub

## Learning Modules

| Module          | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| Wireshark Notes | Installation, packet capture, display filters, and interface basics |
| TCP/IP          | Networking models, addressing, ports, TCP, and UDP                  |
| DNS Analysis    | DNS queries, responses, and record types                            |
| HTTP Analysis   | HTTP methods, headers, responses, and status codes                  |

## Lab Methodology

1. Establish a safe and authorized lab environment.
2. Generate or obtain suitable sample network traffic.
3. Capture and inspect packets using Wireshark.
4. Apply relevant display filters to isolate protocols.
5. Record observations and explain the underlying networking concepts.
6. Save appropriate screenshots and document the results.

## Safety and Responsible Use

This repository is intended for educational purposes.

All live traffic capture, scanning, and analysis will be limited to systems and networks I own or have explicit permission to test. Sample captures will be used where appropriate.

I will avoid publishing credentials, personal information, private network details, or other sensitive data.
